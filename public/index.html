Características del Proyecto

Este proyecto esta pensando para poder ayudar a todos los que quieran adentrarse en el mundo de JavaScript.

Nosotros comenzamos de 0 y sabemos que puede resultar dificil para personas sin experiencia "como nosotros"

Lo que esperamos de este proyecto es poder ayudarte y ayudarnos a aprender juntos mientras creamos esta pagina
